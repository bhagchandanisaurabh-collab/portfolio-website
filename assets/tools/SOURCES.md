# Tools section icons

The following local brand SVGs are from Simple Icons 16.0.0:
https://github.com/simple-icons/simple-icons/tree/16.0.0/icons

Files and published brand colors: arcgis.svg (#2C7AC3), cesium.svg (#6CADDF),
css.svg (#663399), fastapi.svg (#009688), gdal.svg (#5CAE58),
geopandas.svg (#139C5A), git.svg (#F05032), googleearthengine.svg (#4285F4),
leaflet.svg (#199900), maplibre.svg (#396CB2), openlayers.svg (#1F6B75),
and qgis.svg (#589632). Only the root fill was changed; paths are unmodified.
Color metadata and original source links:
https://github.com/simple-icons/simple-icons/blob/16.0.0/data/simple-icons.json

github.svg and mapbox.svg retain their existing black brand marks.

The ArcGIS mark is used for ArcGIS Pro; Simple Icons records Esri's
ArcGIS Pro overview as its source. The Mapbox mark identifies Mapbox GL JS.
HTML uses the HTML5 mark. Logos are identifiers, not endorsements.
